# Deep Research v3 — 多Agent深度研究报告生成器

## 核心改进（融合 Rhino/Deep-Research-skills 优点）

- ✅ **保留**：三角色Agent并行（行业分析师/风险审计师/数据专家）
- ✅ **保留**：实时行情快照（A股代码+RSI+支撑压力位）
- ✅ **保留**：时间轴锚定规则（三层分离：历史/当前/预期）
- ✅ **保留**：投资标的格式（高确定性/ETF/回避标的）
- ✅ **新增**：Outline制（结构化调研大纲，7个固定维度）
- ✅ **新增**：断点续传（checkpoint.json，中断后可续跑）
- ✅ **新增**：字段校验（validate_json.py，确保每个维度信息完整）
- ✅ **新增**：分批执行（每批N个结果，完成后主Agent可先汇总）

## 架构

```
用户请求
    ↓
Step 1: outline_generator.py → 生成结构化大纲（7个调研维度 + 字段定义）
    ↓
Step 2: research_coordinator.py → 并行搜索7个子问题，收集约100+条证据
    ↓
Step 3: Agent并行调研（sessions_spawn，分批执行 + 断点续传）
   - 每个子问题一个prompt文件（out_dir/prompt_{slug}.txt）
   - 支持checkpoint，跳过已完成 item
   - validate_json.py 验证字段完整性
    ↓
Step 4: 三角色Agent综合分析（并发）
   Agent A = 行业分析师（市场规模、竞争格局、受益方向）
   Agent B = 风险审计师（漏洞、风险、相反观点）
   Agent C = 数据专家（数字、统计、反直觉发现）
    ↓
Step 5: 综合推理 → 机构级研报
    ↓
Step 6: 实时行情快照（fetch_realtime.py，A股代码批量查价）
    ↓
Step 7: 保存至 ~/Documents/[Topic]_Research_[date]/
    ↓
Step 8: 飞书发送给用户
```

## 核心脚本

| 脚本 | 作用 |
|---|---|
| `outline_generator.py` | 生成调研大纲（sub_questions + fields） |
| `research_coordinator.py` | 并行搜索7个子问题的证据 |
| `agent_executor.py` | 分批执行Agent调研，带断点续传 |
| `validate_json.py` | 校验JSON是否覆盖所有字段 |
| `fetch_realtime.py` | 批量查询A股/ETF实时行情 |

## 输出规格

生成内容：
- 核心观点（3句话）
- 最重要3个数字 🔢（标出）
- 最大发现（相比市场共识的亮点）
- **【必含】投资标的建议**
  - 🔴 高确定性：个股名称（代码）+ 简明逻辑 + 当前状态标注（强势/整理/可关注）
  - 🟡 中确定性：（条件和逻辑说明）
  - ✅ ETF推荐：代码 + 适合策略（定投/均线回归/支撑位）
  - ❌ 回避标的：代码 + 简短理由
- 最大风险（逻辑崩塌的前提假设）
- 跟踪指标（可量化验证指标）
- 时间轴总图（关键事件节点，区分已发生/预期/不确定）
- 子问题交叉验证（矛盾点解读）

## 【关键规范】时间轴锚定规则

**所有报告的时间锚点是"当前"（由用户指定或当前日期）。**

### 三层分离：

**第一层：当前状态（时间锚点）**
- 语气词：目前、现在、截至X年X月、当前
- 规则：只写当前正在发生的事实，2024/2025年数据不能作为主要论据直接使用

**第二层：因果回溯（2024-2025年）**
- 语气词：2025年X导致……、在此之前……、2024年发生……
- 规则：时间顺序叙述——先发生什么→后发生什么→现在结果是什么

**第三层：前瞻展望（当前之后）**
- 【已确认】政策已生效，趋势明确
- 【预期】基于现有信息的推断，不确定
- 【不确定】前提条件较多，随变量变化

### 时间线总图（每份报告必须有）

| 时间节点 | 关键事件 | 状态 |
|---------|---------|-----|
| 2024年初 | X事件 | 已发生 |
| 2025年6月 | Y事件（重要节点） | 已发生 |
| 2026年1月 | Z政策生效 | 已发生 |
| 2026年4月 | 【当前锚点】 | 当前 |
| 2026年Q2-Q3 | 预期事项A | 预期 |
| 2027年 | 预期事项B | 预期/不确定 |

### "已发生事实 vs 市场预期"必须明确区分

禁止：将预期当事实写、将历史数据当现状写。

## 使用示例

```
用户："帮我深度研究储能行业出口2026"

执行流程：
  ① outline_generator.py → 生成结构化大纲（7个调研维度 + 字段定义）
  ② research_coordinator.py → 并行搜索7个子问题的证据，约100+条结果
  ③ agent_executor.py → 分批执行Agent调研（支持断点续传）
     [主Agent为每个子问题生成prompt文件，然后sessions_spawn并发执行]
  ④ 3个角色Agent综合分析（行业/风险/数据，并发）
  ⑤ 主Agent综合所有分析 → 生成完整研报文本
  ⑥ fetch_realtime.py → 批量查询研报中所有A股/ETF代码的实时行情
  ⑦ 将行情数据填入报告对应位置
  ⑧ 保存至 ~/Documents/储能行业出口Research_[date]/
  ⑨ 通过飞书发送给用户
```

## 断点续传机制

执行 `agent_executor.py <output_dir>` 时：
1. 读取 `checkpoint.json`，跳过已完成的子问题
2. 只执行未完成的批次
3. 每完成一个子问题，立即更新checkpoint
4. 中断后重新运行，自动从断点继续

验证失败时：输出包含缺失字段列表，主Agent可针对性补充调研。

## 并行Agent启动命令（主Agent调用sessions_spawn）

三个Agent必须同时启动（并发），使用 `session: spawn, mode: run, runtime: subagent`：

**Agent A — 行业分析师**
```
你是一位资深行业分析师。请基于以下证据集，对主题「{topic}」进行深度分析，输出结构化报告。

分析维度：
1. 市场规模与增速（近3年数据，当前最新数字）
2. 竞争格局（主要玩家、市场份额变化、护城河）
3. 受益方向与具体标的（A股代码、逻辑、当前市场表现）
4. 政策驱动力与持续性

要求：
- 区分"已发生事实"和"市场预期"，分别标注
- 每个结论必须附上证据来源编号
- 投资标的必须给出：股票代码 + 公司名 + 核心逻辑 + 当前状态

---证据---
{all_evidence}
```

**Agent B — 风险审计师**
```
你是一位资深风险审计师。请对主题「{topic}」进行全面风险审查，找出最可能出错的逻辑。

分析维度：
1. 估值风险（当前PE/PB是否透支预期）
2. 竞争风险（是否有颠覆性威胁）
3. 政策风险（补贴退坡、政策转向的影响）
4. 供应链风险（原材料/关键零部件依赖）
5. 最危险的叙事陷阱（哪个主流观点最可能被证伪）

要求：
- 每个风险点给出：风险类型 + 触发条件 + 可能跌幅
- 明确列出"不能相信什么"，与乐观派观点对照

---证据---
{all_evidence}
```

**Agent C — 数据专家**
```
你是一位量化数据专家。请对主题「{topic}」进行数据分析，找出最有影响力的数字。

分析维度：
1. 关键指标TOP10（市场规模、市占率、增速、均价、利润率等）
2. 历史规律（同比/环比规律、季节性）
3. 机构预测与实际值的差距（预期差分析）
4. 反直觉发现（与直觉相悖的数据结论）

要求：
- 每个数字必须注明来源和日期
- 标出最重要3个数字（用 🔢 标记）
- 找出1-2个"市场忽视但很重要"的反直觉结论

---证据---
{all_evidence}
```

## 与普通调研的区别

| 维度 | 普通搜索→总结 | deep-research-v3 |
|---|---|---|
| 搜索 | 单次搜索 | 分问题并行多路搜索 |
| 分析 | 单Agent | 三角色并行交叉验证 |
| 覆盖 | 容易遗漏 | 7个固定维度 + 字段校验 |
| 行情 | 无 | A股实时+技术位 |
| 投资标的 | 无或不完整 | 必须包含高/中确定性+ETF+回避 |
| 断点 | 无 | 中断可续传 |
| 时间轴 | 混用历史当前 | 三层严格分离 |
